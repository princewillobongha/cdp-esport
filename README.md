# CDP ESPORT Website

Static, responsive website starter for Comrades Democratic Party (CDP ESPORT).

## Files
- index.html — full one-page website
- style.css — responsive styling
- script.js — mobile menu and footer year
- assets/cdp-main.webp — supplied main logo
- assets/cdp-community.jpg — supplied community logo

## Before publishing
Replace the `#` links for TikTok, Facebook, Community Groups and President's Handle with the official URLs.
Connect the contact form to an email/form service if you want submissions to be delivered.
